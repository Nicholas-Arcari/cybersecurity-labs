SCREENSHOT PoC - 09 - Personalizza l'ambiente desktop

Questa cartella raccoglie gli screenshot proof-of-concept (PoC) di questo lab.
Le immagini vanno catturate eseguendo davvero il lab: sono evidenza di
esecuzione reale e non vanno mai fabbricate.

COSA CATTURARE
- (config) il terminale con il comando di setup eseguito e l'esito atteso.
- Evidenzia (riquadro o freccia) la riga o il valore che dimostra il risultato.
- Formato .jpg o .png. Nome file suggerito: 09-customize-desktop-environment-poc.jpg

COME COLLEGARE L'IMMAGINE NEL README (dopo averla salvata in questa cartella)
