SCREENSHOT PoC - GNU Radio Flowgraphs - Elaborazione del Segnale Personalizzata

esecuzione reale e non vanno mai fabbricate.

COSA CATTURARE
- lo spettro/segnale catturato (in lab).
- Evidenzia (riquadro o freccia) la riga o il valore che dimostra il risultato.
- Formato .jpg o .png. Nome file suggerito: gnu-radio-flowgraphs-poc.jpg
